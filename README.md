# Taller de Regresión Lineal - Especialización en Analítica y Ciencia de Datos
**Universidad de Cundinamarca**

## Descripción del Proyecto
Este repositorio contiene la implementación práctica de un modelo de **Regresión Lineal** para predecir las ventas basándose en la inversión publicitaria, utilizando datos abiertos extraídos mediante Python[cite: 1, 18].

## Estructura del Repositorio
* `src/`: Contiene el Jupyter Notebook principal (`TallerRegresiónLineal.ipynb`)[cite: 1].
* `data/`: Espacio destinado a los conjuntos de datos del proyecto[cite: 1].
* `figures/`: Carpeta con las gráficas y visualizaciones generadas durante el análisis[cite: 1].
